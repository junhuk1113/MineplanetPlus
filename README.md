# 마인플래닛+ 모드
마인플래닛 서버(mineplanet.kr)에서 동작하는 편의성 모드입니다.
다양한 편의성 기능을 제공합니다.
+ 던전 도우미 원작자 Blastlong님에게 깊은 감사를 표합니다.

## 모드 기능 설명
### 던전 도우미
던전 서버에서 사용할 수 있는 기능입니다.
레이드 던전 입장 쿨타임 타이머 기능, 던전 직업 스킬 활성/쿨타임 표시 기능, 커스텀 인첸트 고서, 행운의 룬 등급별로 구별 할 수 있도록 텍스쳐 수정 기능이 있습니다.

### 피시 헬퍼
마인플래닛 서버 커스텀 낚시 시스템에 대응하는 낚시 도우미입니다. 등급별로 구별이 어려운 물고기 텍스쳐를 등급별로 다르게 적용하였습니다. 물고기 카운터 기능을 켜시면 물고기 등급별로 낚시 통계를 볼 수 있습니다. 
추가로 토템을 사용하시는 분들을 위해 토템타이머 기능을 개발했습니다. 
모드 최초 사용시 토템 메뉴, 낚시 스탯 메뉴를 한 번 열었다 닫아주시면 토템 스펙을 모드가 자동으로 적용합니다.

### 스킬타이머 
4가지 생산 스킬의 활성 시간, 쿨타임을 출력해줍니다. 설정에서 원하는 스킬만 볼 수 있게 설정하실 수 있습니다.

### 확성기 타이머
확성기 쿨타임을 출력해줍니다.

## 모드 설치법
페더 클라이언트는 페더 런처에서 모드 넣는 메뉴로 들어가신 후 올바른 버전을 선택하신 후에 모드 파일을 넣어주세요. .minecraft폴더에 mods에 넣을 시 동작하지 않습니다. 일반 페브릭 로더로 사용하실 분은 .minecraft폴더에 mods에 첨부된 파일을 넣어주세요. 모드 사용이 처음이신 분은 페더 클라이언트를 설치하셔서 사용하는 것을 추천드립니다. **MODMENU 모드도 함께 넣어주시는 것을 권장합니다.**
